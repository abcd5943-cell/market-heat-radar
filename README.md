市場資料整理工具

個人使用的市場資料整理與視覺化練習專案。

使用 Python 處理不同來源的公開市場及經濟數據，並透過簡單的網頁介面呈現部分統計結果。

專案內容

* 市場及經濟數據整理
* 歷史資料統計與指標計算
* 基本圖表呈現
* GitHub Actions 排程更新
* GitHub Pages 靜態網頁

資料來源

本專案使用或參考以下資料來源：

* Cboe
* FINRA
* FRED（Federal Reserve Economic Data）
* Yahoo Finance

不同資料來源的更新頻率、發布時間及使用限制可能有所不同，部分資料亦可能存在缺漏或修訂。

使用說明

本專案主要供個人學習、測試與研究使用。

部分資料處理程序透過 GitHub Actions 執行，實際更新情況取決於資料來源及排程執行結果。

網頁所呈現的統計數值僅供參考，不保證資料完整性、即時性或準確性。

相關資料及其使用方式應遵守原始資料提供者的使用條款。
